# i18n（宿主侧）

本指南从应用开发者的角度介绍 i18n：宿主消息和语言切换。如果你要编写翻译自身字符串的组件，请参见[组件编写](05-authoring-components.zh-CN.md)。

## 宿主消息

宿主拥有应用级字符串。它们位于 `apps/demo/src/locales/demo.json`：

```json
{
  "en": {
    "nav": { "dashboard": "Dashboard" }
  },
  "zh-CN": {
    "nav": { "dashboard": "仪表盘" }
  }
}
```

框架使用 vue-i18n。应用创建全局 composer：

```ts
// apps/demo/src/i18n.ts
import { createI18n } from "vue-i18n";

export const i18n = createI18n({
  legacy: false,
  locale: "en",
  fallbackLocale: "en",
  missingWarn: false,
  fallbackWarn: false,
});
```

## 语言消息如何到达外壳

`AdminProvider` 在初始化时把宿主消息注入全局 composer。外壳从偏好设置 store 读取当前语言，并同步 composer。

菜单标签、标签页标签和页面内容都通过全局 composer 翻译：

```ts
i18n.global.t("nav.dashboard")
```

## 选择语言

外壳偏好设置控件切换当前语言。demo 提供 `en` 和 `zh-CN`。
