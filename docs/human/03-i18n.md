# i18n

The framework uses vue-i18n. Locale schemas are declared per package and
typed. The host owns the active locale and the root messages.

## Two message layers

- **Host messages** — app-level strings such as menu labels. They live in
  the host app and seed the global vue-i18n composer.
- **Package messages** — component strings shipped by the framework
  packages. They live in each package's `locales/` folder.

Package components resolve their strings with `createComponentI18n`. Keys
missing from the package fall back to host messages through the root
composer.

## Component i18n

A component creates a local composer:

```tsx
import { createComponentI18n } from "@noob-naive-ui/i18n";
import exampleMessages from "../../locales/Example.json";

const { t } = createComponentI18n({
  messages: exampleMessages,
  libraryId: "noob-naive-ui:ui",
  componentId: "Example",
});

// t("title") resolves against Example.json for the active locale
```

`getComponentI18n` resolves the nearest component composer from a
descendant:

```tsx
const { t } = getComponentI18n();
```

## Locale schema augmentation

The framework derives locale types from a single source. Each package
declares its full locale schema through `LibraryOverridesRegistry`:

```ts
declare module "@noob-naive-ui/registry" {
  interface LibraryOverridesRegistry {
    "noob-naive-ui:ui": {
      locale: Record<NoobUiLocaleName, NoobUiLocale>;
      theme: NoobUiThemeComponents;
    };
  }
}
```

The `NoobUiLocale` interface is empty by default. A component registers
its slice via module augmentation:

```ts
// packages/ui/src/components/example/i18n.ts
declare module "@noob-naive-ui/ui" {
  interface NoobUiLocale {
    Example: NoobUiExampleLocale;
  }
}
```

Important: a side-effect module that only augments types must be imported
somewhere in the compilation graph. Otherwise TypeScript never sees the
augmentation, and the component key resolves to `never`.

```ts
import "./i18n"; // register the NoobUiLocale augmentation
```

## Locale files

`apps/demo/src/locales/demo.json` holds the host messages:

```json
{
  "en": {
    "nav": { "dashboard": "Dashboard" }
  },
  "zh-CN": {
    "nav": { "dashboard": "仪表盘" }
  }
}
```

The shell preference control switches the locale. The active locale seeds
the global composer at provider setup.
